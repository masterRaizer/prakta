# Пример: лабораторные работы 7–16 (C#, Windows Forms)

Учебный разобранный пример. Работы выполнены для **демонстрационного варианта**
`c = (a² − b) / (a + 2b)`, которого нет в таблице вариантов. Пример показывает, как устроены
отладка, обработка исключений, классы и тестирование; свою работу выполняйте по своему варианту.

Подробное руководство по каждой работе — `Руководство_ЛР7-16.docx`.

## Как открыть
1. Visual Studio 2019 или новее, рабочая нагрузка «Разработка классических приложений .NET».
2. Открыть `LabWorksExample.sln`, назначить `LabWorks.App` автозагружаемым проектом, F5.
3. Тесты: «Тест» → «Обозреватель тестов» → «Запустить все».

## Состав
| Проект | Что внутри |
|---|---|
| `src/LabWorks.Core` | Библиотека: формула и `VariantCalculator` (ЛР 10, 15), `SafeCalculator` (ЛР 8), `Person` (ЛР 11), `Tabulator` (ЛР 13), тесты и отчёт (ЛР 14–16) |
| `src/LabWorks.App` | Windows Forms, .NET Framework 4.8: по вкладке на каждую работу |
| `tests/LabWorks.Tests` | MSTest: модульные и интеграционные тесты |

ЛР 9 (техническое задание) и ЛР 12 (тестирование интерфейса) — документы; как их составить,
описано в руководстве.
